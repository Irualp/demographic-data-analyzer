# Demographic Data Analyzer

This project analyzes demographic data using Python and Pandas.
The dataset used in the demographic analysis was obtained from the UCI Machine Learning Repository. The dataset is known as the Adult dataset or Census Income dataset, originally extracted from the 1994 U.S. Census database. It contains demographic and income-related information and is commonly used in data analysis and machine learning tasks.

## Files
- demographic_data_analyzer.py
- adult.data.csv

## How to run
```bash
python demographic_data_analyzer.py
